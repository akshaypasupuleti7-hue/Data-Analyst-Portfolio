# Banking & Transaction Analytics Dashboard

## 📊 Project Overview

This project analyzes banking transactions, payment methods, transaction statuses, customer accounts, and loan information using Microsoft Power BI.

The dashboard provides an interactive overview of banking performance and helps identify transaction trends, payment behavior, and failed or pending transactions.

## 🎯 Business Objectives

- Monitor overall banking transaction performance
- Analyze transaction amounts by status
- Compare different payment methods
- Track monthly transaction trends
- Analyze accounts across cities
- Monitor paid, pending, and failed payment amounts
- Track loan volume and total loan amount
- Identify successful versus failed/pending transactions

## 📈 Dashboard Analysis

### Transaction Amount by Status
Shows the distribution of transaction amounts across successful, pending, and failed transactions.

### Payment Method Analysis
Compares transaction amounts across:
- Net Banking
- UPI
- Debit Card
- ATM

### Monthly Transaction Amount
Displays transaction amount trends over time and helps identify monthly fluctuations.

### Accounts by City
Shows the number of accounts across different cities.

### Payment Status Amount
Compares the amount associated with paid, pending, and failed payment statuses.
